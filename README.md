主要功能：实现24V直流输入，6V-19V直流输出，最大输出电流2A的功能（理论上支持最大电流15A）
详细介绍：
· 基本电路板块：
1. 功率回路为同步BUCK拓扑；
2. 控制& 采样等弱电电路的供电模块（小功率DC-DC电源芯片电路+LDO稳压）；
3. 电流采样模块（INA282）和电压采样模块（OPA2188）基于datasheet 示例改造搭建，电流采样带直流偏置，可以双向采样；
4. MOS驱动电路（IR2104）（根据开关频率、VCC、Qg，以及datasheet示例选择合适的Cboot、Dboot等搭建）；
5. stm32f103c8t6（TIM、ADC&DMA、EXTI、UART、I2C、主控PID& 数字滤波）；
6. OLED显示、USART串口发送、LED& 蜂鸣器提示、旋转编码器、按键交互等。
· 保护：TVS静电保护、PMOS防反接保护、继电器保护、软件保护（含OCP、OVP、OPP）。
· 控制算法：软启动+ 模式切换+ 带限幅的增量式PID串级电流电压环双环控制占空比输出。

·注意事项：
1. 由于驱动芯片为IR2104，该驱动芯片内置死区时间500ns（典型值），20kHz的开关频率一个开关周期为50us，死区时间占比已经达到1%，
所以开关频率不建议超过30kHz，最理想的应用情况应为20kHz，电流噪声相对较弱，同时一个开关周期的时间不至于太短，太快的开关频率容易导致半桥直通，存在一定的炸管风险。

2. 给主控供电一定要先用LDO稳压至3.3V，再供应，DCDC芯片输出电压纹波相对LDO较大，不适合需要稳定电平的MCU以及各微电模块。
